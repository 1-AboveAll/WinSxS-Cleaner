## Overview

This project is based on the Tiny11 Core script. Unlike the original Tiny11 builds, this script does **not** remove built-in Windows apps or optional features. Instead, it focuses on reducing system size and improving performance through safe cleanup and optimization.

The script performs the following tasks:

* Cleans the **WinSxS** component store.
* Removes **Windows Recovery Environment (WinRE)**.
* Removes **Microsoft OneDrive**.
* Disables or removes **Windows Update services**.
* Applies various **registry optimizations and system tweaks**.
* Cleans temporary and unnecessary system folders to reduce disk usage.
